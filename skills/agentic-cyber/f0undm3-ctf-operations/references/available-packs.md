# Available packs

Every pack in this library, with what it covers. Each is a separate ZIP the user uploads
independently. When a pack you need is not installed, name its ZIP here rather than pointing
at a file the user cannot open.

| Pack | ZIP | Covers |
|---|---|---|
| f0undm3-ctf-operations | `f0undm3-ctf-operations.zip` | Coordinate offensive-security work end to end: triage, pwn, reverse, web, crypto, forensics, OSINT, scoped engagements, team handoffs, and publication-style F0undM3/numpav writeups and reports. |
| exam-mode | `exam-mode.zip` | Run a graded exam or assessment end to end: per-host phase tracking from evidence, load sets that pull every needed pack at once, scope and tool-restriction enforcement, report-ready state. |
| research-mode | `research-mode.zip` | Hunt vulnerabilities in open-source software and see them fixed: attack-surface mapping, sink hunting, patch diffing, local proof, coordinated disclosure with a tracked timeline, and CVE assignment. |
| ctf-ad | `ctf-ad.zip` | Attack Active Directory and hybrid Entra ID: enumeration, Kerberos (roasting, delegation, RBCD), AD CS/ESC, NTLM relay, ACL abuse, lateral movement, DCSync, trusts. For CTFs, exam labs, and pentests. |
| ctf-ai-ml | `ctf-ai-ml.zip` | Test AI, ML, LLM, and agent/MCP systems: prompt injection, tool poisoning, adversarial inputs, and model attacks. For CTFs, exam labs, bug bounty, and security research. |
| ctf-cloud | `ctf-cloud.zip` | Attack AWS and Azure/Entra: IAM/RBAC privesc, managed-identity and metadata credential theft, compute-service RCE, secret extraction, and unauth entry. For ARTE/AZRTE/CARTP and cloud pentests. |
| ctf-crypto | `ctf-crypto.zip` | Attack cryptographic implementations and protocols: classical ciphers, RSA, ECC, PRNGs, lattices, and protocol flaws. For CTFs, exam labs, and applied crypto research. |
| ctf-forensics | `ctf-forensics.zip` | Investigate disk, memory, network, log, steganography, and file-recovery artifacts with preserved evidence. For CTFs, DFIR, exam labs, and authorized investigations. |
| ctf-malware | `ctf-malware.zip` | Analyze malware and suspicious binaries safely: obfuscation, packers, PE/.NET, loaders, and C2 protocols. For CTFs, malware research, and incident response. |
| ctf-misc | `ctf-misc.zip` | Solve encoding, jail-escape, VM, sandbox, protocol, DNS, and unusual-format problems. For CTFs, exam labs, and authorized security research. |
| ctf-osint | `ctf-osint.zip` | Corroborated open-source research: geolocation, media, social, web, and DNS evidence. For CTFs, recon during authorized engagements, and threat intelligence. |
| ctf-pentest | `ctf-pentest.zip` | Pentest fundamentals: network/service enumeration, attacking common services, file transfers, shells & payloads, password attacks, and professional reporting. For OSCP, CPTS, CRTeamer prep. |
| ctf-pivoting | `ctf-pivoting.zip` | Reach internal networks through a compromised host: SSH/chisel/ligolo-ng tunneling, port forwarding, SOCKS proxies, multi-hop pivots. For CPTS, CRTE, OSCP labs, pentests, and multi-host CTF. |
| ctf-privesc | `ctf-privesc.zip` | Escalate to root/SYSTEM/Administrator: Linux sudo/SUID/capabilities/cron/kernel and Windows tokens (SeImpersonate/Potato), services, UAC, credential hunting. For OSCP, CPTS, CRTP labs and pentests. |
| ctf-pwn | `ctf-pwn.zip` | Exploit memory-corruption bugs once understood: overflows, ROP, heap, shellcode, kernel, and sandbox escapes. For CTFs, OSED-style labs, and exploit development. |
| ctf-redteam | `ctf-redteam.zip` | Authorized red-team ops: C2 infra, initial access/phishing, payload delivery, EDR-evasion concepts, lateral movement, persistence, OPSEC, ATT&CK, reporting. For CRTeamer/CRTO/CRTL/CRTP/CRTE prep. |
| ctf-reverse | `ctf-reverse.zip` | Reverse binaries, bytecode, firmware, VMs, packed programs, and anti-analysis logic. For CTFs, exam labs, malware analysis, and vulnerability research. |
| ctf-web | `ctf-web.zip` | Find and exploit web application flaws: auth, injection, SSRF, XSS, deserialization, file handling, and APIs. For CTFs, exam labs, bug bounty, and pentests. |
| ctf-wireless | `ctf-wireless.zip` | Attack corporate Wi-Fi end to end: WPA2/WPA3/enterprise breaks, WPS, evil twins, rogue-AP/karma, WEP, then pivot onto the internal VLAN to AD domain compromise. For OSWP and Wi-Fi pentests. |
| ctf-writeup | `ctf-writeup.zip` | Write reproducible technical writeups after a solve or confirmed vulnerability, with evidence, exact steps, and verification. For CTFs, exam reports, and findings. |
| solve-challenge | `solve-challenge.zip` | Triage a new challenge or target, identify its dominant category, preserve evidence, and select the right specialist workflow. For CTFs, exam labs, and assessments. |
